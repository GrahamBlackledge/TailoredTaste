# TailoredTaste
Tailored Taste is a personal chef business aimed at giving clients a high end fine dining experince in the comfort of their own homes.
This Repo will be used for the code base of the website and booking management system, as well as part of my Bachelors of IT capstone project.


### Aim of project

The aim of this project is to create a stylish and easy to use website that will allow clients to book private dining experiences and from the back end allow the owner to manage these easily.

### Main Features 

- Stylish public website
- Easy to access information
- Straightforward customer form
- Intuitive booking management system and admin dashboard
- Client management /  postgreSQL database
- Able to generate quotes and invoices
  
### Tech Stack
- Next.js
- React
- Tailwind
- PostgreSQL
